# Panoptes docs

Technical notes for people running, changing or contributing to Panoptes. The top-level [README](../README.md) stays short on purpose, and the details live here.

| Doc | Read it when you want to… |
|---|---|
| [features.md](features.md) | know exactly what each room, animation and indicator means |
| [configuration.md](configuration.md) | change log folders, host or port, or choose between the dev and standalone servers |
| [architecture.md](architecture.md) | understand how a log line becomes a moving character |
| [development.md](development.md) | find the tests, or add a tool mapping, a UI string or a redaction pattern |

See also [CONTRIBUTING.md](../CONTRIBUTING.md) and [SECURITY.md](../SECURITY.md).

When you change behaviour, configuration or architecture, update the matching doc in the same PR.

---
name: stop
description: Stop the Panoptes server that /panoptes:open started.
disable-model-invocation: true
---

Run this command once with the Bash tool, exactly as written:

```bash
panoptes stop
```

Then tell the user what it printed, in one line, and stop. If the shell says the `panoptes` command isn't found, say that Panoptes isn't installed, so nothing is running.

Don't run any other command, and don't read or change any files.
